# Frontend Product Website

Static frontend project with product data and browser-side JavaScript.

## Project structure

- `index.html`
- `main.js`
- `product.js`
- `styles.css`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Frontend-Project.git
cd Frontend-Project
```

Open `index.html` in a browser or use a local static server.
